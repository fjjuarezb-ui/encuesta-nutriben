Pasos de configuración

  1. Crea cuenta gratis en supabase.com
  2. Crea nuevo proyecto (cualquier nombre)
  3. Ve a SQL Editor → New Query
  4. Pega y ejecuta el contenido del archivo nutriben_supabase_setup.sql
  5. Ve a Settings → API y copia URL + anon key
  6. Pégalos arriba y guarda
